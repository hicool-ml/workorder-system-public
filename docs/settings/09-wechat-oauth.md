# 微信公众号登录（微信 OAuth）

> 路径：侧边栏 → **设置** → **微信登录**
> 路由：`system-settings/wechat-oauth`（仅管理员）

让用户用**普通微信**直接认证登录。用户在企业微信/通知消息里点开链接后，若未登录，可在登录页点「微信登录」，跳转微信完成授权，实现免密登录。**无需安装企业微信、不依赖手机验证码。**

> 前置条件：必须拥有一个**已认证的微信公众号**（服务号或订阅号），且在公众号后台配置了「网页授权域名」。

## 工作原理

微信 OAuth 返回的是匿名 `openid`（不包含姓名/工号等身份信息），因此无法像 CAS/OIDC 那样自动建号。采用「**一次性绑定 + 之后免密**」的流程：

1. 用户点「微信登录」→ 微信授权页
2. 授权后回调，系统取得 `openid`
3. 已绑定 `openid` 的用户 → 直接登录（记住登录状态）
4. 未绑定的用户 → 进入绑定页，输入系统用户名/密码完成绑定
5. 之后该微信每次打开系统都自动免密登录

## 配置项

| 字段 | 设置键 | 说明 |
|------|--------|------|
| 认证开关 | `wechat_oauth_enabled` | 启用后登录页显示「微信登录」入口 |
| AppID | `wechat_oauth_appid` | 公众号「设置与开发 → 基本配置」中获取 |
| AppSecret | `wechat_oauth_secret` | 公众号 AppSecret |
| 授权 Scope | `wechat_oauth_scope` | `snsapi_base`（静默，仅 openid，推荐）/ `snsapi_userinfo`（需用户授权，额外获取昵称头像） |

授权回调地址：`http(s)://你的域名/wechat/callback`（在页面只读展示）。

## 接入步骤

1. 准备一个**已认证**的微信公众号，获取 AppID / AppSecret
2. 公众号后台「设置与开发 → 公众号设置 → 功能设置 → 网页授权域名」添加本系统域名（仅域名，不带路径、不加 http）
3. 在本页填写 AppID / AppSecret，选择 Scope，勾选启用并保存
4. 登录页出现「微信登录」按钮，用户点击后跳转微信授权
5. 首次登录的用户进入绑定页，输入系统账号密码完成一次性绑定，之后免密登录

## 用户绑定管理

- 微信绑定关系保存在 `users.wechat_openid` 字段（按 AppID 唯一）
- 用户管理页可查看/清除某用户的「微信OpenID」；清除后该微信需重新绑定
- 同一个系统账号只能绑定一个微信；已绑定的账号若用其他微信登录会被拒绝
- 绑定 `wechat_openid` 不会改变用户的 `account_type`，微信只是登录方式，账号来源保持不变

## 关联设置键

`wechat_oauth_enabled`、`wechat_oauth_appid`、`wechat_oauth_secret`、`wechat_oauth_scope`。

## 常见问题

- **回调提示「认证回调验证失败」**：多为 state 过期或微信返回错误 code，重新登录即可
- **提示「微信认证失败」**：检查 AppID/AppSecret 是否与公众号匹配，以及网页授权域名是否配置正确
- **snsapi_userinfo 授权时无反应**：若公众号未认证或未配置网页授权域名，微信会直接报错，需先完成前置条件
