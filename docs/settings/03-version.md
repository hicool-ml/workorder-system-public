# 版本管理

> 路径：侧边栏 → **设置** → **版本管理**
> 路由：`settings/version`（仅管理员）

记录和展示系统的版本演进。顶部卡片展示当前版本号、发布日期、系统名称；可在此发布新版本并查看历史。

## 功能

### 当前版本卡片

展示三块信息：当前版本号（徽标）、发布日期、系统名称。这三项与「系统设置」页的对应字段共享数据。

### 更新版本

点击右上角「更新版本」打开弹窗，填写：

| 字段 | 说明 |
|------|------|
| **新版本号** | 如 `2.1.0`，会写入 `system_version` |
| **发布日期** | 写入 `system_release_date`，默认今天 |
| **发布说明** | 可选，本次版本的更新内容，存为 `version_notes_{版本号}` 设置项，构成版本历史 |

保存后当前版本卡片立即刷新为新版本。

### 版本历史

点击「版本历史」展开列表，按时间倒序展示所有曾经发布过的版本（版本号 + 发布说明 + 时间）。数据来自所有 `version_notes_*` 设置项。

## 关联设置键

- `system_version`、`system_release_date`：当前版本
- `version_notes_{版本号}`：各历史版本的发布说明

## 注意

- 版本历史依赖发布说明来生成。如果发布时「发布说明」留空，该版本不会出现在历史列表中
- 这里的「版本」只是给用户看的展示性版本号，与代码的 git tag / `composer.json` 版本无自动联动，需手动维护
