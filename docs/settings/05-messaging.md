# 消息设置

> 路径：侧边栏 → **设置** → **消息设置**
> 路由：`settings/messaging`（仅管理员）

消息设置本身是一个导航入口页，用五张卡片把通知相关的配置聚合到一起。点击卡片跳转到对应的详细配置页。

## 五个入口

### 通知规则

跳转到「事件 × 通道」矩阵页面。这里控制**哪个工单事件**触发**哪种通知通道**（站内通知、短信、企业微信、钉钉、飞书）。例如可以设定「工单分配时发短信给工程师，但不发站内通知」。

事件类型包括工单创建、分配、开始处理、解决、完结、关闭等关键节点。每个事件可独立开关站内通知、短信、企业微信、钉钉、飞书五个通道。

### 短信配置

跳转到短信网关配置页，配置短信服务商凭证和发送参数：

| 字段 | 设置键 | 说明 |
|------|--------|------|
| **服务商** | `sms_provider` | `aliyun`（阿里云）/ `tencent`（腾讯云）/ `custom`（自定义网关） |
| **启用** | `sms_enabled` | 总开关 |
| **签名名称** | `sms_sign_name` | 短信签名，需在服务商后台报备审核 |
| **AccessKey** | `sms_access_key` | 服务商 API 密钥 |
| **AccessSecret** | `sms_access_secret` | 服务商 API 密钥 |
| **SDK AppID** | `sms_sdk_app_id` | 腾讯云需要 |
| **API URL** | `sms_api_url` | 自定义网关的接口地址 |
| **请求方法** | `sms_method` | `GET` / `POST`，自定义网关用 |
| **API Key** | `sms_api_key` | 自定义网关的鉴权 Key |

页面内提供「测试发送」按钮，可向指定手机号发一条测试短信验证配置。

此外，短信配置页内还有一块独立的**报修人短信**区域（不受上方「通知规则」矩阵控制）：

| 设置项 | 设置键 | 说明 |
|--------|--------|------|
| **受理通知开关** | `creator_sms_enabled` | 工单受理时（创建即分配或工程师接单）向报修人发送一次 |
| **满意度调查开关** | `creator_survey_enabled` | 工单完结时向报修人发送一次，报修人回复 `1`/`0` 自动回写评价 |
| **受理模板（有预约）** | `sms_creator_acceptance_tpl_with_appt` | 含 `{预约时间}` 的受理文案 |
| **受理模板（无预约）** | `sms_creator_acceptance_tpl_no_appt` | 无预约时间的受理文案 |
| **满意度模板** | `sms_creator_survey_tpl` | 满意度调查文案 |

两套开关均默认关闭、相互独立；模板支持 `{系统名称}` `{工程师电话}` `{预约时间}` `{工单编号}` 占位符。开启满意度调查后，需在短信服务商后台配置上行回复回调地址为 `/sms/reply`，否则评价无法自动回写。完整步骤见 [通知配置指南 → 报修人短信](../NOTIFICATION_GUIDE.md#报修人短信受理通知--满意度调查)。

### 企业微信

跳转到企业微信通知配置页，支持两种模式（可按 `wecom_send_mode` 切换）：

- **群机器人 Webhook**：填一个 Webhook 地址即可，工单创建 @所有人、分配/超时 @指定工程师
- **自建应用**：填 CorpID / Secret / AgentID，通过应用消息推送

页面还提供 SSL 证书管理（上传 `cacert.pem`、开关 SSL 验证）和企业微信测试发送。

### 钉钉

跳转到钉钉通知配置页，支持两种模式（可按 `dingtalk_send_mode` 切换）：

- **自定义机器人 Webhook**：填 Webhook 地址 + 加签 secret，工单创建 @所有人、分配/超时 @指定工程师（userid 优先，手机号兜底）
- **工作通知（企业内部应用）**：填 AppKey / AppSecret / AgentId，工作通知直达个人钉钉

页面内提供测试发送按钮。配置步骤见 [通知配置指南 → 钉钉配置](../NOTIFICATION_GUIDE.md#钉钉配置)。

### 飞书

跳转到飞书通知配置页，支持两种模式（可按 `feishu_send_mode` 切换）：

- **自定义机器人 Webhook**：填 Webhook 地址 + 加签 secret，工单创建 @所有人、分配/超时 @指定工程师（按 user_id/open_id）
- **自建应用**：填 App ID / App Secret，通过 IM 消息直达个人飞书（无 @all 语义，需指定接收人）

页面内提供测试发送按钮。配置步骤见 [通知配置指南 → 飞书配置](../NOTIFICATION_GUIDE.md#飞书配置)。
