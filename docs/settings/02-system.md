# 系统设置

> 路径：侧边栏 → **设置** → **系统设置**
> 路由：`settings/system`（仅管理员）

配置系统的基础展示信息和外部可达地址。这里的「版本号」和「发布日期」与「版本管理」页共享同一份数据，在此处修改即等于发布版本（但不会写入版本历史的发布说明，正式发布建议走版本管理页）。

## 配置项

| 字段 | 设置键 | 说明 |
|------|--------|------|
| **系统名称** | `system_name` | 全站标题、浏览器标签、PWA 名称、企业微信通知抬头都会用到。默认 `校园网工单系统` |
| **版本号** | `system_version` | 当前系统版本，默认 `2.0.0` |
| **发布日期** | `system_release_date` | 当前版本的发布日期 |
| **系统访问地址** | `system_url` | 系统对外的实际访问 URL（如 `http://192.168.1.100:8099`）。**企业微信通知里的工单链接会拼接此地址**，务必填客户端能访问到的地址，否则通知里的链接打不开 |

## 操作

- **保存设置**：表单提交后写入 `system_settings`，立即生效

## 注意

- `system_url` 留空时，企业微信通知里的工单链接会回退到 `config('app.url')`。`APP_URL` 通常是内网/容器地址，发给用户的链接很可能不可达，所以**强烈建议在此显式填写**
- 修改系统名称后，已添加到主屏幕的 PWA 应用名不会自动更新，用户需重新添加
