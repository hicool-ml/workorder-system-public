# 详细设置

> 路径：侧边栏 → **设置** → **详细设置**
> 路由：`settings/all`（仅管理员）

整张 `system_settings` 表的直接视图。当某个设置项在前面的子页里没有暴露编辑入口时，可以在这里直接改它的原始值。可以理解为设置系统的「注册表编辑器」。

## 列表展示

表格列出所有设置项，列含义：

| 列 | 说明 |
|----|------|
| **设置键** | `system_settings.key`，如 `system_name`、`sms_provider` |
| **值** | 当前值。布尔类型显示为「是/否」徽标，其余显示原始值（超长截断） |
| **类型** | `string` / `boolean` / `integer` / `float` / `json` / `text` 等 |
| **描述** | 设置项的人类可读说明 |
| **公开** | `is_public` 标记。标记为「是」的设置项可通过公开设置 API 读取（如系统名称） |
| **操作** | 编辑、删除 |

移动端切换为卡片列表布局，字段相同。

## 操作

- **编辑**：弹出对话框修改该键的值（键名只读）。保存时按设置项的 `type` 自动做类型转换
- **删除**：移除该设置项（二次确认）。删除后系统会回退到代码内的默认值或报错，**谨慎使用**

## 使用场景

- 子页面未提供编辑入口的高级设置项（如某些通知规则底层键）
- 排查「保存了但没生效」的问题，来这里核对原始值是否被正确写入
- 误删设置后，配合「注册设置」页的「初始化默认设置」恢复

## 注意

- 这里改的是底层键值，**改错可能导致功能异常**。不确定的设置项不要随意修改或删除
- 删除设置项是不可逆的（无回收站），删除前务必确认它不是关键配置
- 布尔类型在编辑框里需输入 `1`/`true` 或 `0`/`false`，与界面上勾选框表现不同
