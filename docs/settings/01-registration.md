# 注册设置

> 路径：侧边栏 → **设置** → **注册设置**
> 路由：`settings/registration`（仅管理员）

控制本地账号的自助注册行为。注意：**CAS / 统一身份认证**用户不受此页控制，他们由学校身份系统自动创建。

## 配置项

| 项 | 说明 |
|----|------|
| **开放注册** | 顶部开关。开启后登录页出现「注册」入口，允许访客自助注册本地账号；关闭后入口消失 |
| **默认用户角色** | 新注册用户自动获得的角色：`普通用户` / `工程师` / `工单管理员`。多数情况应保持「普通用户」 |
| **需要邮箱验证** | 开启后，注册邮箱需点击验证链接后才激活账号（需系统已配置 SMTP 发信） |

## 操作

- **保存设置**：把当前表单写入 `system_settings`
- **初始化默认设置**：右上角按钮，补齐所有缺失的默认设置项（已有项不会被覆盖）。升级或误删设置时可用它恢复

## 关联设置键

`registration_enabled`、`default_user_role`、`require_email_verification`。

## 注意

- 关闭注册不影响已注册用户登录，只拦住新注册入口
- 若开启邮箱验证但未配置 `MAIL_*`，用户收不到激活邮件会卡在未激活状态
- 生产环境建议关闭自助注册，改用管理员手动建号或走 CAS 统一认证
