fix: 外部审计复核修复（SSO 锁死 / 报表 XSS / 短信通道 / 备份 4 项等）

复核确认并修复（外部 AI 审查清单逐项核实后）：
- SSO 用户被强制改密锁死（blocker）：CAS/OIDC 建号密码为随机值且
  password_changed_at 恒 null → ForcePasswordChange 要求输 current_password
  改密 → 永久死锁。修复：SSO 建号直接置 password_changed_at=now()
  （本地密码不参与 SSO 认证）+ 迁移解锁存量 SSO 用户
- 报表页存储型 XSS：treemap 数据 json_encode 无 JSON_HEX_TAG，
  分类名含 </script> 可注入。改用 @json（Blade 内置 HEX_TAG/APOS/AMP/QUOT）
- 阿里云短信通道不可用：签名按 POP RPC 规范以 "GET&%2F&" 构造但用 POST
  发送 → 签名必然校验失败。发送方法改 GET 与签名一致
- mysqldump 备份密码入命令行：-p{$pass} 未转义且 ps 可见。
  改 MYSQL_PWD 环境变量 + proc_open（与恢复侧一致）
- 附件备份盘错位：v3.1 附件迁私有盘后备份仍只打包 storage/app/public
  → 新附件全部漏备。改为双目录打包（attachments 主 + public 兼容旧文件），
  恢复端写入私有盘（修复恢复后重新暴露 /storage 直链的问题）
- 备份恢复白名单收紧：DROP TABLE 仅允许 IF EXISTS 形态（防恶意备份清表注入）
- 短信设置页密钥回显：sms_access_secret / sms_api_key 改 password 输入
  + 留空不覆盖（补齐上轮遗漏的短信页）
- OIDC 错误日志 body 截断 200 字符（token/userinfo 响应含令牌片段与 PII）
- 清理 AppServiceProvider 死代码：$_SERVER 强制 HTTP + url 宏全局相对化
  （经核验从未生效；若被"修活"会破坏 SSO 绝对回调与 HTTPS 识别）
